# Нестабильный захват GPS/Galileo: сверка с рабочими IQ

Дата: 2026-10-18. Причина аппаратного срыва **не установлена**.

Пользователь подтвердил: старые `GPS_BDS_GAL_L1.c8` и `piter.c8` работают
на том же дроне, новые `USA_STATIC.C8` и `USA_CIRCLE.C8` — нет. Это исходный
факт диагностики; повторная проверка работоспособности эталонов не требуется.
Карта и модель дрона не используются как объяснение регрессии.

## Что проверено в сигнале

- Проверялись именно новые файлы из `sd_20261018`, revision `a8c19e5`,
  GPS 68 / Galileo 74 dB-Hz, 4.2 MS/s, IQ8, 300 s.
- Перестановка E1-B/E1-C не обнаружена: все 50 data PRN и 50 pilot PRN
  побитно соответствуют независимой реализации PocketSDR
  `03787da53c65a8eb291eec571b6412ec470aeb17`.
- CS25 совпадает в порядке передачи: `0011100000001010110110010`.
- Новый статический файл: PocketSDR принял 1306 страниц E1-B без ошибок;
  все девять E1-C синхронизировали вторичный код, потерь захвата не было.
- В 1939 парных эпохах E1-B/E1-C разность TOW по модулю 100 ms равна нулю.
- Относительная фаза data/pilot измерена корреляцией непосредственно в IQ,
  без предположения о правильности Rust-кода. Для трёх SV старого файла:
  от −0.67° до +1.39° по модулю 180°; нового: от −0.61° до +1.79°.
  Разворота пилота на 90° относительно рабочего эталона нет. Эта проверка
  по модулю 180° сама по себе не устанавливает абсолютный знак nav-символов.
- Непрерывное интегрирование Doppler за 300 s для GPS13/Galileo02/29
  сверено с геометрией для статики и круга: расхождение кода менее
  0.00075 primary chips; несущей — до 1.23 cycles, нарастающих плавно.
  Это проверка накопления модели, а не сертификация RF-тракта.

## Уровень не даёт готового объяснения

На выборках 1/30/150/299 s комплексный RMS относительно 127:

| Файл | RMS | Доля компонент на границах −128/+127 |
| --- | --- | --- |
| Рабочий GPS_BDS_GAL_L1 | 0.892 | около 18.3% |
| Рабочий piter | 0.351 | около 0.005% |
| Новый USA_STATIC | 0.395 | около 0.038% |

`piter` опровергает объяснение исключительно низким общим RMS. Изменять
общий gain или баланс систем по этой таблице без отдельного доказательства
причины нельзя. Приём PocketSDR/GNSS-SDR также не заменяет аппаратный результат.

## Изменения и границы

Добавлены независимые тесты `tests/galileo_pilot_reference.rs` и фикстура
`tests/fixtures/galileo_e1_primary.sha256`. Хеши получены по знаку первого
из 12 CBOC-подотсчётов каждого чипа в `sdr_gen_code(E1B/E1C, PRN)` PocketSDR.
Проверены 100 последовательностей длиной 4092, без поднесущей.

По прямому указанию пользователя C/N0 оставлен как в `a8c19e5`, без добавления
затухания. Предложенная правка default elevation fade отменена полностью.
Сгенерированные IQ и рабочие эталоны не изменены; SD была прочитана и размонтирована.
Коммит/push и новая генерация в рамках этой сверки не выполнялись.

Проверки: полный suite 203 passed / 0 failed / 6 ignored, fmt и строгий Clippy;
после отмены изменения C/N0 отдельно повторён его тест. Эти результаты
не означают исправления аппаратного захвата. RF-01 остаётся открытым.
