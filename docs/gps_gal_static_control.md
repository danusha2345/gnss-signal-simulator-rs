# Статический контроль GPS + Galileo

Контроль подготовлен после сообщения пользователя: динамический вариант 68/74 dBHz
по-прежнему показывает ноль на дроне. Гипотеза о влиянии движения пока не подтверждена
аппаратным сравнением.

На SD в папке `GPS` используются короткие имена:

| Файл | Движение | Пресет |
|---|---|---|
| `USA_STATIC.C8` | неподвижная точка | `presets/gps_gal_static_control_4m2_300s.json` |
| `USA_CIRCLE.C8` | круг R=100 м, 10 км/ч | `presets/gps_gal_circle100m_10kmh_4m2_300s.json` |

Рядом с каждым `.C8` находится одноимённый `.TXT`:

```text
center_frequency=1575420000
sample_rate=4200000
```

Остальные параметры одинаковы: GPS L1CA + Galileo E1, IQ8, 300 с,
GPS 68 dBHz / Galileo 74 dBHz, начальная точка 48.4928° N, 114.2847° W,
высота 100 м, время 2025-06-05 10:05:30 UTC и тот же RINEX.
Сравнение JSON исключило дополнительные различия, кроме меток/путей и движения.

В статическом пресете скорость равна нулю, сегмент `Const` длится 300 с.
Проверка публичного API траектории подтвердила неизменные ECEF и нулевую скорость
в моменты 0, 1, 150 и 300 с. Код генератора для этого контроля не редактировался.

GNSS-SDR 0.0.20 обработал полный статический файл: 2696 PVT-эпох,
первый фикс на 30,1 с, последний на 299,6 с, максимум 15 наблюдений.
Горизонтальная ошибка относительно постоянной точки: медиана 5,21 м,
максимум 8,74 м. Это программная проверка, не подтверждение приёма дроном.

Размер каждого IQ-файла — 2 520 000 000 байт.

- `USA_STATIC.C8`: SHA-256 `e20618f1f2d6beb6aba084304496c7cde6ce4be5f760df69b8b0e68d152e7563`.
- `USA_CIRCLE.C8`: SHA-256 `f150be0cf6fb49649111a72050e07736048852cd049f4c6c1d94a53446ed18f7`.

Для аппаратного сравнения сначала воспроизвести `USA_STATIC.C8`, затем
`USA_CIRCLE.C8` на тех же настройках TX, расстоянии и приёмнике. Если статический
вариант тоже не принимается, движение не объясняет отсутствие приёма само по себе.

Материалы проверки: `/home/danik/storage/gnss_rust-static-control-20261017/`.
Оба файла хранятся на диске 2 ТБ в `gnss_rust/generated_files/`.

`USA_STATIC.C8` полностью прочитан с SD и диска 2 ТБ; обе SHA-256 совпали
с указанной выше. `.TXT` проверены побайтно. Динамический файл только
переименован в `USA_CIRCLE.C8`, его данные не менялись. SD размонтирована.

## После ревизии 2026-10-17

Текущий preset использует mount `/run/media/danik/external_ssd_2tb/`.
Старые хеши выше относятся к ранее созданным файлам, а не к результату
генерации исправленным кодом. Изменения и проверки описаны в
[ICD-отчёте](gnss_icd_conformance_report.md). Исправленный `elevationAdjust=true`
теперь ослабляет GPS ниже зенита; указанный GPS CN0 — базовый уровень.
Явный override Galileo задаётся без этой коррекции.
