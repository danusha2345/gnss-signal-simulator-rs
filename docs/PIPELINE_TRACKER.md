подтверждением E5a, GLONASS и L1C.

## Журнал выполнения

- 2026-10-17: проверены версии зависимостей, записан план; начат этап 1.

- 2026-10-17, этап 1: время сохраняется как `UtcTime`, JSON читается один раз;
  legacy-вход направлен в тот же путь. Неверная дата, координаты, формат,
  Fs вне целых kHz и длительность вне целых ms отклоняются. Поддерживаемые
  UTC-даты: 1980-01-06…2099-12-31, метка секунды 60 пока отклоняется.
- Пустой RINEX не приводит к успешному noise-only файлу. При повторной
  загрузке очищаются старые nav-данные; неудачная загрузка инвалидирует сценарий.
- IQ записывается через create_new partial → flush → size check → sync_all →
  rename → sync каталога на Unix. Отказы ДО rename сохраняют старую версию.
  Если sync каталога после rename завершился ошибкой, новый файл уже опубликован,
  но долговечность переименования не гарантирована. При SIGKILL может остаться
  partial; он не подменяет финальный файл. На неизвестных сетевых FS атомарность
  отдельно не проверялась.
- Статистика возвращается из цикла синтеза: фактические отсчёты/байты, активные
  каналы, clipping и время. Флаги специальных CUDA/AVX-512 kernels — false:
